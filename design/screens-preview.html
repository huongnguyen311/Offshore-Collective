M04 · Core
Booking Calendar
Signature Moment #3: rounded-square date glyphs echo the brand mark; boat identity reuses Home's header component. The key names each state (available, booked, blocked, standby-available, unclaimed); Christmas Window's tint shows only when that window falls in the visible month. Per A.6/A.7, tapping any day in an intact Weekend or Long Weekend block selects/prices the whole block (C.4); once unclaimed past Friday midnight (C.5), days become individually selectable again. Named Holidays use a distinct dashed info-tint marker (C.7), display-only. Standby-available (12–13, A.6/C.27, added 2026-09-14) replaces a leftover "Held" state from the removed Rayglass 2400 Towing Approval flow; its exact claim mechanics still need confirming against A.6/C.27. Tab bar is dropped for a back arrow, matching Review & Confirm and Booking Detail.
